# প্রতারক খোঁজি (Protarok Khuji) 🔍⚠️

বাংলাদেশের অনলাইন প্রতারকদের কমিউনিটি ডেটাবেজ — স্ক্যামারের নাম বা মোবাইল নম্বর দিয়ে খুঁজুন, প্রমাণসহ রিপোর্ট করুন।

## ✨ ফিচারসমূহ

- **স্মার্ট সার্চ** — নাম বা মোবাইল নম্বর দিয়ে স্ক্যামার ডেটাবেজে খুঁজুন (বাংলা/ইংরেজি দুটোতেই কাজ করে)
- **রিপোর্ট সাবমিশন** — প্রতারকের নাম, নম্বর, প্রতারণার ধরন, বিবরণ, ক্ষতির পরিমাণ ও স্ক্রিনশট প্রমাণসহ রিপোর্ট
- **যাচাই ব্যাজ** — "যাচাই করা" ও "যাচাই চলছে" স্ট্যাটাস
- **ফিল্টার** — সব / যাচাই করা / যাচাই চলছে
- **প্রমাণ গ্যালারি** — প্রতিটি রিপোর্টে স্ক্রিনশট প্রমাণ (মডালে বিস্তারিত)
- **অ্যানিমেশন** — স্ক্রল রিভিল, কাউন্ট-আপ স্ট্যাটস, হোভার ইফেক্ট, ফ্লোটিং ব্লব
- **ফুল রেসপন্সিভ** — মোবাইল-ফার্স্ট ডিজাইন, হ্যামবার্গার মেনু

> ⚠️ এটি একটি **ডেমো** — ডেটা কাল্পনিক, আর রিপোর্টগুলো আপাতত ব্রাউজারের `localStorage`-এ সেভ হয়। পরবর্তী ধাপে ব্যাকএন্ড ডেটাবেজ ও অ্যাডমিন যাচাই যুক্ত হবে।

## 🛠️ টেকনোলজি

- শুদ্ধ HTML + CSS + Vanilla JavaScript (কোনো ফ্রেমওয়ার্ক/বিল্ড স্টেপ নেই)
- Google Fonts: Hind Siliguri + Noto Serif Bengali
- ডিজাইন অনুপ্রেরণা: [Unseen Bangladesh](https://unseenbangladesh.com/)-এর বাংলা-ফার্স্ট ক্লিন UI

## 📁 ফোল্ডার স্ট্রাকচার

```
protarok-khuji/
├── index.html        # একক পেজ (হিরো, সার্চ, রিপোর্ট, ফর্ম, FAQ)
├── css/
│   └── style.css     # সম্পূর্ণ স্টাইল + অ্যানিমেশন
└── js/
    ├── data.js       # ডামি ডেটা + localStorage হেল্পার
    └── app.js        # সার্চ, রেন্ডার, মডাল, ফর্ম লজিক
```

## 🚀 চালানোর নিয়ম

কোনো ইনস্টলেশন লাগবে না — শুধু ব্রাউজারে `index.html` খুলুন।

অথবা GitHub Pages-এ ডিপ্লয় করুন: Settings → Pages → Branch: `main` → Save.
